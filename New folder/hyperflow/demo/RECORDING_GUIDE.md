# HyperFlow Demo Recording Guide

## Pre-Recording Checklist

### Mobile Recording Setup
- [ ] Charge iPhone to 100%
- [ ] Enable "Do Not Disturb"
- [ ] Hide notifications
- [ ] Clean up home screen (remove other apps from view)
- [ ] Set brightness to maximum
- [ ] Close all background apps
- [ ] Test wallet connection beforehand
- [ ] Have test USDC ready on testnet

### Desktop Recording Setup
- [ ] Close unnecessary apps/windows
- [ ] Clean VS Code workspace
- [ ] Test npm install beforehand
- [ ] Have demo project ready
- [ ] Set up OBS with 1080p60
- [ ] Test microphone levels
- [ ] Prepare script teleprompter

### Camera/Audio
- [ ] Good lighting (ring light or natural window light)
- [ ] Quiet environment
- [ ] Quality microphone (Blue Yeti or similar)
- [ ] Test audio levels (aim for -12dB to -6dB)

## Recording Process

### Mobile Segment
1. Start screen recording on iPhone
2. Record in one continuous take if possible
3. Do a practice run first
4. If you mess up, pause and restart that section
5. Keep gestures smooth and deliberate
6. Show confidence - no hesitation in taps

### Desktop Segment
1. Use OBS with 1920x1080 canvas
2. Record terminal and VS Code separately
3. Type commands slowly and clearly
4. Show cursor movements deliberately
5. Keep browser window consistent size

### Voiceover
1. Record in a closet or with sound dampening
2. Stand while recording (better voice projection)
3. Smile while talking (yes, it affects your voice)
4. Record script in 10-15 second chunks
5. Leave 1 second of silence before/after each take
6. Do 3 takes of each section, pick the best

## Post-Production Workflow

### Video Editing (DaVinci Resolve or Final Cut Pro)
1. Import all footage
2. Create 1920x1080 timeline at 30fps
3. Edit mobile segments first
4. Add desktop segments
5. Trim all dead space aggressively
6. Add smooth transitions (0.3s max)
7. Color grade for consistency

### Audio Editing (Audacity or Adobe Audition)
1. Noise reduction on voiceover
2. Normalize to -3dB
3. Add slight compression
4. EQ to enhance clarity
5. Remove mouth clicks/pops
6. Sync perfectly with video

### Final Touches
1. Add text overlays (URLs, key points)
2. Background music at 20% volume
3. Sound effects for UI interactions (subtle)
4. Color grading for professional look
5. End card with CTA

### Export Settings
- Format: MP4 (H.264)
- Resolution: 1920x1080
- Frame rate: 30fps
- Bitrate: 10-15 Mbps
- Audio: AAC, 320kbps

## Backup Plan
If you can't get perfect takes:
1. Use screen recordings with text overlays instead of voiceover
2. Add captions for accessibility anyway
3. Focus on showing, not telling
4. A silent demo with good music can work too
